## Closed Beta distribution

This repository is the **official distribution channel** for **MSFS Preset Manager Pro**.

It contains installation and update packages only.  
**The application source code is maintained separately and is not published here.**

> [!IMPORTANT]
> Closed Beta builds are prerelease software intended for invited testers.  
> Because this distribution repository is public, release assets are publicly downloadable; invitations are not a technical access restriction.

## First installation

Go to the [Releases](https://github.com/Theooooo33/PMP-Releases/releases) page and open the version you want to install.

Download **only**:

`PMP.PresetManager.PRO.App-win-x64-beta-Setup.exe`

Run the installer normally. PMP uses a **per-user installation** and does not require administrator elevation during normal setup.

## Already installed?

You do **not** need to download update packages manually.

Open:

**PMP → Settings → Check for updates**

PMP will detect the latest compatible Closed Beta release and use the appropriate Velopack package automatically.

## What are the other files?

| Asset | Purpose |
| --- | --- |
| `...Setup.exe` | **First installation — this is the file testers should download** |
| `...full.nupkg` | Full update package / fallback |
| `...delta.nupkg` | Small incremental update package |
| `releases.win-x64-beta.json` | Velopack release metadata |
| `...Portable.zip` | Portable distribution artifact; not the normal install path |
| `Source code (zip / tar.gz)` | Automatically generated by GitHub from this distribution repository — **not PMP application source code** |

## Update channel

Current public distribution channel:

**Windows x64 · Closed Beta**

## Security note

Windows packages are currently **unsigned**. Windows SmartScreen may display an unknown-publisher warning on some systems.

HTTPS distribution protects transport, but it does **not** replace Authenticode publisher signing.
