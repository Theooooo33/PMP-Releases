# MSFS Preset Manager Pro — Releases

Official distribution repository for MSFS Preset Manager Pro.

This repository contains installation and update packages only. Source code is maintained separately.

Closed Beta builds are prerelease software distributed to invited testers. Because this repository is public, its download assets are publicly accessible; invitations are not a technical access restriction.

For a first installation, download the `PMP.PresetManager.PRO.App-win-x64-beta-Setup.exe` asset from the appropriate release. Existing installations can check for updates in Settings.

Windows packages are currently unsigned. Windows SmartScreen may display an unknown-publisher warning. HTTPS distribution does not constitute publisher code signing.
